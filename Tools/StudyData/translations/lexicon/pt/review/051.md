# To review: pt lexicon batch 051

### G2748 κέδρος (Kidron)
- note: The English distinguishes 'Cedron' (NT) and 'Kidron' (OT); the Bíblia Livre has 'Cedrom' for both (Jhn.18:1, 2Sa.15:23). 'Essays' is Lightfoot's title, kept. Abbott-Smith's '2Sam, 1Ki' (no verse) written with the Portuguese abbreviations.

### G2750 κειρία (graveclothes)
- note: 'AV.' here is Aristophanes' Aves (Birds), copied as in the source; '1 1,' copied as in the source. 'Pr, l.with' (Proverbs, LXX Pro.7:16) written 'Pv, l. com'.

### G2756 κενός (empty)
- note: Source '(with)' is a garbled '(c)' (after (a), (b)): rendered '(c.)'.

### G2767 κεράννυμι (to mix)
- note: The quoted definition (LS) is translated.

### G2782 κήρυγμα (preaching)
- note: Source 'genitive cubic.' is a misread 'gen. subjc.' (subjective genitive), rendered 'genitivo subj.'.

### G2802 Κλαύδη, Καῦδα (Cauda)
- note: The gloss follows the Bíblia Livre ('Clauda', Act.27:16); the definition keeps both forms the lexicon names.

### G2810 Κλεόπας (Cleopas)
- note: Name as in the Bíblia Livre (Luk.24:18 'Cleofas'; it also spells Κλωπᾶς 'Cleofas', Jhn.19:25). 'B1.' (for Bl.) copied as in the source.

### G2816 κληρονομέω (to inherit)
- note: 'Words' is Dalman's title, kept.

### G2826 κλινίδιον (bed)
- note: Source 'a conch' is a misprinted 'a couch': rendered 'pequeno leito'.

### G2828 κλισία (group)
- note: Source '(with)' is a garbled '(c)' (after (a), (b)): rendered '(c.)'.

### G2832 Κλωπᾶς (Clopas)
- note: Name as in the Bíblia Livre (Jhn.19:25 'Cleofas'), which spells Κλεόπας the same way (Luk.24:18); the English distinguishes Clopas and Cleopas.

### G2835 κοδράντης (penny)
- note: 'farthing' is the AV's rendering, kept in English.

### G2840 κοινόω (to profane)
- note: Source 'Winer Notes' (capital N) is the verb 'notes': rendered 'observa'.

### G2841 κοινωνέω (to participate)
- note: 'Pr, l.with' (Proverbs, LXX Pro.1:11) written 'Pv, l. com'.

### G2842 κοινωνία (participation)
- note: 'Communion' is the title of DB's article, kept.

### G2846 κοιτών (bedroom/chamberlain)
- note: 'Sources' is Kennedy's title, kept.

### G2854 κολλούριον (eye salve)
- note: 'hil' copied as in the source.

### G2855 κολλυβιστής (moneychanger)
- note: 'of.' (for cf.) copied as in the source.

### G2858 Κολασσαεύς (Colossae)
- note: The gloss 'Colossae' follows the English (the entry is 'a Colossian'). Abbott-Smith's 'Col., tit.' (the epistle's title) written 'Cl., tít.'.

### G2860 κολυμβάω (to swim)
- note: 'AI.' (for Al.) copied as in the source.

### G2862 κολωνία (Roman colony)
- note: 'colonic' (for colonia) copied as in the source.

### G2866 κομψότερον (better)
- note: Comparison with colloquial English kept: «to be doing finely», with the Portuguese after it.

### G2869 κοπάζω (to abate)

### G2873 κόπος (labor)

### G2884 κόρος (cor)

### G2889 κόσμος (world)
