# To review: pt lexicon batch 074

### G6081 συμπίπτω (be downcast)
- note: An LSJ article (via STEPBible, '(ML)'): Latinized author labels such as 'Herdotus Historicus' kept as in the source; works and plain author names written in Portuguese.

### G6083 σύνοιδα (be conscious of)
- note: Source 'C. prop. reflex.' is a misprinted 'pron.' (the reflexive pronoun ἐμαυτῷ): rendered 'pron. reflex.'. 'ύν-οιδα' (for σύν-οιδα) copied as in the source.

### G6084 Τιτίος (Titius)
- note: Tício as in the usual Portuguese versions (the Bíblia Livre's text has only Justo here).

### G6095 Ἀρνὶ (Arni)
- note: Names as in the Bíblia Livre (Hezrom, Jerameel, Calebe, Segube, Asur, Aminadabe); Arni and Admim as in the usual Portuguese versions of Luke 3:33 (the Bíblia Livre has Arão there, as the KJV has Aram).

### G6632 ἀφυστερέω (to withhold)
- note: Source 'l.with' (a misread 'l. c.') rendered 'l. com'. Source 'Ne, i.e.' is probably the same 'l. c.' misread: rendered 'Ne, l. com'.

### G7530 εὖγε (well done)
- note: An LSJ article (via STEPBible, '(ML)'): Latinized author labels such as 'Herdotus Historicus' kept as in the source; works and plain author names written in Portuguese.

### G9315 συνεπιτίθημι (to join in making an attack)
- note: An LSJ article (via STEPBible, '(ML)'): Latinized author labels such as 'Herdotus Historicus' kept as in the source; works and plain author names written in Portuguese. The garbled '̀ 6 6̀ το' (for 'to') copied as in the source.
