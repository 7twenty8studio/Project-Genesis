# To review: es lexicon batch 029

### G0107 Ἀζώρ (Azor)
- note: Gloss and name 'Azor' are the same in Spanish (RV1909 Azor).

### G0112 ἄθεος (without God)
- note: Source '(with)' is a garbled '(c)' (the third subsection), rendered '(c.)'. Source typo 'denyiyig' read as 'denying'.

### G0129G αἷμα (blood)
- note: Source '(with)' is a garbled '(c)' (the third subsection), rendered '(c.)'. 'AR on Eph' kept as a work reference (Armitage Robinson on Ephesians), 'on' translated.

### G0129H αἷμα ((Field of) Blood)
- note: Source '(with)' is a garbled '(c)' (the third subsection), rendered '(c.)'. 'AR on Eph' kept as a work reference (Armitage Robinson on Ephesians), 'on' translated.

### G0154 αἰτέω (to ask)
- note: 'dupl. accusative' here means a double accusative: rendered 'doble acusativo'.

### G0166 αἰώνιος (eternal)
- note: Source '(with)' is a garbled '(c)' (the third subsection), rendered '(c.)'.

### G0169 ἀκάθαρτος (unclean)
- note: Source '(with)' is a garbled '(c)' (the third subsection), rendered '(c.)'.

### G0179 ἀκατάλυτος (indestructible)
- note: Gloss 'indestructible' is the same word in Spanish.

### G0184 Ἀκελδαμά (Akeldama)
- note: Source 'Akeldama dama' (a garbled transliteration) rendered 'Acéldama dama' (RV1909 Acéldama), the stray 'dama' kept.

### G0190 ἀκολουθέω (to follow)
- note: Source 'poët., away' is a garbled 'poët., a way' (κέλευθος): rendered 'camino'. 'Eutherford' (for Rutherford) kept.

### G0191 ἀκούω (to hear)
- note: 'dupl. accusative' means a double accusative ('doble acusativo'); source 'genitive pars.' read as 'gen. pers.'. Work titles (Essays) kept.

### G0207 Ἀκύλας (Aquila)
- note: Name 'Aquila' is spelled the same in the RV1909.

### G0214 ἀλαλάζω (to wail)
- note: RV's English rendering 'clanging' kept as quoted.

### G0224 ἄλευρον (flour)
- note: Source 'real' is a misprint for 'meal' (flour): rendered 'harina'.

### G0237 ἀλλαχόθεν (from elsewhere)
- note: Source runs 'seeMM' together; kept joined ('véaseMM') so the sigla match.

### G0239 ἀλληλουϊα (hallelujah)
- note: 'hallelujah, alleluia' both rendered by the one Spanish word 'aleluya'.

### G0243 ἄλλος (another)
- note: English 'else' kept as the cognate cited (Eng. else).
