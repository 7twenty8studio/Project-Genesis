# To review: es lexicon batch 034

### G0867 ἄφιξις (departure)
- note: Source 'M, Pro.26:1-28, n.' is a garbled 'M, Pr., 26, n.' (Moulton's Prolegomena), kept as written.

### G0887 ἀχλύς (mist)
- note: Source '§ with' is a garbled '§ c' (Trench's section c), rendered '§ c'.

### G0891 ἄχρι (until)
- note: Source '(with)' is a garbled '(c)' (the third subsection), rendered '(c)'.

### G0912 Βαραββᾶς (Barabbas)
- note: Source 'accusative to Jerome' is a garbled 'acc. to' (according to): rendered 'según'.

### G0926 βαρύς (weighty)
- note: EV's English rendering 'grievous' kept as quoted.

### G0947 βδελυκτός (abominable)
- note: Gloss 'abominable' is the same word in Spanish.

### G0954 Βεελζεβούλ (Beelzebul)
- note: AV/RV's English rendering 'Beelzebub' kept as quoted; the Reina-Valera spelling Beelzebú is used for the name itself.

### G0959 Βερνίκη (Bernice)
- note: The two spellings Bernice and Berenice are the source's own pair and are kept; Reina-Valera has Berenice (gloss).

### G0962 Βηθαβαρά,Βηθανία (Bethany)
- note: The source gloss is 'Bethany' (Betania) though the article is Bethabara (Betábara); both kept as given.

### G0963 Βηθανία (Bethany)
- note: Source 'accusative to Jerome' is a garbled 'acc. to' (according to): rendered 'según'.
