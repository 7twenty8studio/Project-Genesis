# To review: es lexicon batch 065

### G4484 Ῥήγιον (Rhegium)
- note: Rhegium in Sicily per Abbott-Smith (it is in Calabria, Italy); translated as written.

### G4492 ῥιζόω (to root)
- note: EV's English 'rooted' kept as quoted, with the Spanish after it.

### G4494 ῥιπίζω (to toss about)
- note: Philo's title 'de inter. round.' (probably a misread 'de incorr. mundi') kept as written.

### G4508 ῥυπαρός (filthy)
- note: Source 'l.with' is a garbled 'l. c.' (loc. cit.), rendered 'l. con' as in the phrase table.

### G4513 Ῥωμαϊκός (Latin)
- note: Source 'Anthology Palantina' (Anthologia Palatina, a title, run together with the previous word) kept as written.

### G4518 σαβαχθάνι (sabachthani)
- note: Source 'l.with' is a garbled 'l. c.' (loc. cit.), rendered 'l. con' as in the phrase table. Source 'thou host forsaken me' is a typo for 'thou hast forsaken me'.

### G4519 σαβαώθ (hosts)
- note: Source 'l.with' is a garbled 'l. c.' (loc. cit.), rendered 'l. con' as in the phrase table. 'Ja 54' (probably Jas 5:4) kept as written.

### G4524 Σαδώκ (Zadok)
- note: The source gives two spellings ('Sadoc, Zadok'); 'Sadoc' is the RV1909's, 'Zadok' kept as the second form.

### G4527G Σαλά (Sala)
- note: Name 'Sala' is spelled the same in Spanish (RV1909, Luke 3:35); the source's 'Shalah' is given as 'Sela'.

### G4527H Σαλά (Shelah)
- note: The source's 'Shalah' is given as 'Sela'.
