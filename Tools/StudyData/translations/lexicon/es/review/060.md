# To review: es lexicon batch 060

### G3925 παρεμβολή (barracks)
- note: Source '(with)' is a garbled '(c)' (the third subsection), rendered '(c.)'. The source adds the παρ-εμ-βάλλω article; translated too.

### G3928 παρέρχομαι (to pass by)
- note: Source 'accusative lot.' is a misread 'acc. loc.' (accusative of place): rendered 'acusativo loc.'.

### G3930 παρέχω (to furnish occasion)
- note: Source 'prop. reflex.' (twice) is a misread 'pron. reflex.' (reflexive pronoun): rendered 'pron. reflex.'. 'B1.' (for 'Bl.') and 'ut supr.' kept as written.

### G3931 παρηγορία (comfort)
- note: Source 'll. with' (STEPBible's expansion of 'll.c.') rendered 'll. con'.

### G3936 παρίστημι (to stand by)
- note: Source 'of.' is a misprint for 'cf.': rendered 'cf.'.

### G3941 πάροικος (foreigner)
- note: Source 'Iuser.' is a misread 'Inscr.' (inscriptions) and 'metapb.' a misprint for 'metaph.': rendered 'inscr.' and 'metáf.'. Kennedy's 'Sources' kept as the work's title.

### G3942 παροιμία (proverb)
- note: Abbott's 'Essays' kept as the work's title.

### G3951 παροτρύνω (to incite)
- note: Source 'find.' is a misprint for 'Pind.' (Pindar): rendered 'Pind.'.

### G3952 παρουσία (coming)
- note: Source 'l.with' (STEPBible's expansion of 'l.c.') rendered 'l. con'.

### G3954 παρρησία (boldness)
- note: 'He 416' (Heb 4:16) and 'Jn 3:21 Jn 4:17 Jn 5:14' (1 John) kept as codes.

### G3956 πᾶς (all)
- note: 'Phi 2:29', 'Phi 4:6', 'Jhn.2:1o' and 'πάτνα' kept as the source writes them; 'al. mult.' kept (Latin).

### G3958 πάσχω (to suffer)
- note: 'Interp. Corn.' kept as the source writes it.

### G3962 πατήρ (father)
- note: Source '(with)' is a garbled '(c)' (the third subsection), rendered '(c.)'; 'l.with' (STEPBible's expansion of 'l.c.') rendered 'l. con'. 'Words' (Dalman) kept as the work's title.

### G3963 Πάτμος (Patmos)
- note: The name 'Patmos' is the same in Spanish.

### G3964 πατραλῴας (patricide)
- note: Source 'Av' (for AV) kept as written.

### G3968 πατρίς (fatherland)
- note: Source 'fern.' is a misprint for 'fem.': rendered 'fem.'.

### G3969 Πατροβᾶς (Patrobas)
- note: The name 'Patrobas' is the same in Spanish (Reina-Valera, Romanos 16:14).

### G3971 πατρῷος (ancestral)
- note: Gloss 'ancestral' is the same word in Spanish.
