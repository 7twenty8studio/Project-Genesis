# Draft: correction report to eBible.org (not sent)

To: eBible.org (the contact form at ebible.org, or the address they give
for text corrections)
Subject: Bíblia Livre (porbr2018): contractions split by a space

Hello,

Thank you for publishing the Bíblia Livre (porbr2018). We use the
February 2018 USFX (porbr2018_usfx.zip) in Versely, a Bible reading app,
and keep the text exactly as you publish it, with the CC BY 4.0 Brasil
credit.

We noticed 22 places where a Portuguese contraction is split by a
space. In the USFX the contraction's first letter and the rest of the word
fall on either side of an <add> mark with a line break between them, and
the line break reads as a space. For example, John 6:34:

    Senhor, dá-nos sempre
    <add>d</add> este pão.

which displays as "dá-nos sempre d este pão" instead of "deste pão".

The places:
- Psalms 17:13: "d as" (for "das")
- Psalms 17:14: "n esta" (for "nesta")
- Psalms 22:10: "d o" (for "do")
- Psalms 95:10: "d esta" (for "desta")
- Psalms 102:3: "n um" (for "num")
- Proverbs 10:17: "d aquele" (for "daquele")
- Ecclesiastes 8:8: "d esta" (for "desta")
- Isaiah 5:23: "d os" (for "dos")
- Isaiah 14:32: "d aquela" (for "daquela")
- Mark 6:11: "d aquela" (for "daquela")
- Luke 21:34: "d esta" (for "desta")
- John 4:54: "d a" (for "da")
- John 6:34: "d este" (for "deste")
- Acts 1:15: "d aqueles" (for "daqueles")
- Acts 13:14: "n um" (for "num")
- Acts 21:1: "n o" (for "no")
- Acts 21:8: "n o" (for "no")
- Acts 21:18: "n o" (for "no")
- Acts 23:11: "n a" (for "na")
- Acts 26:17: "d este" (for "deste")
- 2 Corinthians 12:5: "D este" (for "Deste")
- Revelation 9:17: "n esta" (for "nesta")

There may also be places where "a os" stands for "aos" (Joshua 24:15,
Ruth 3:2, 1 Chronicles 15:11, 16:42, 17:5, 17:6, 21:2, 21:7, 23:2, 23:6,
25:1, 26:21, 29:25, Psalms 16:3, Isaiah 57:18, Mark 6:11), though "a os"
is correct in other verses, so we leave those to you.

If you correct the files, we'll rebuild from the new edition. Would you
pass this on to the translators if the fix belongs with them?

With thanks,
The Versely team
